# MGMT 2026 W2｜GitHub Pages 發布與課前檢查

updated: 2026-09-16

## 發布方式

1. 建立一個新的 GitHub repository，或開啟指定的既有 repository。
2. 將發布套件中的 `index.html` 與 `.nojekyll` 放在 repository 根目錄。
3. 到 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. 選擇要發布的 branch 與 `/ (root)`，儲存設定。
6. 待 GitHub 顯示正式網址後，使用學生裝置實際測試。

本專案不需要安裝套件、執行建置程序或設定 API 金鑰。

## 本機使用

學生可直接下載 `index.html`，以 Chrome、Edge、Firefox 或 Safari 開啟。作答內容只保存在目前瀏覽器的 `localStorage`，不會自動傳給教師。

新聞原文位於外部出版者網站，因此開啟新聞需要網路；其餘教學內容、作答、語言切換與筆記匯出可在離線狀態使用。

## 教師課前檢查

- [ ] 中文與 English 切換後，學生已輸入的文字不會消失。
- [ ] 未完成 T0 與新聞證據卡時，Prompt Lab 保持鎖定。
- [ ] 完成必填欄位後，可複製 Prompt V1、V2 與新聞決策摘要 Prompt。
- [ ] Prompt V1 與 V2 均完整列出十二封訊息，且順序與學生目前的收件匣排序一致。
- [ ] 重新整理頁面後，作答仍保留在同一瀏覽器。
- [ ] Markdown、JSON、HTML 與列印／PDF 匯出可正常運作。
- [ ] 匯入 JSON 備份後，作答及排序正確還原。
- [ ] 「清除作答」需要兩次確認，且只清除目前網頁的本機資料。
- [ ] 新聞連結可以開啟，日期與標題仍正確。
- [ ] Video 1 與 Video 2 仍可由 NTU COOL 課程頁面觀看。
- [ ] 1366×768 投影與手機直式畫面沒有文字重疊或橫向溢位。

## 建議課堂操作

1. 教師先提醒學生使用自己的瀏覽器與裝置，避免無痕模式。
2. T0 階段不開啟生成式 AI；先完成個人 P–O–L–C、收件匣排序及新聞證據卡。
3. T1 階段將 Prompt 複製到學生選擇的生成式 AI，再把完整回答貼回網頁。
   - V1 使用簡短指令；V2 使用同一組十二封訊息並加入管理標準、格式及限制，以便公平比較 Prompt 設計的影響。
4. No-AI Challenge 階段關閉 AI，完成採納、修正、拒絕與查證判斷。
5. 下課前要求學生至少匯出 Markdown 或 HTML；需要跨裝置接續時，再匯出 JSON 備份。

## 資料與著作權界線

- 不輸入姓名、學號、聯絡資料、機密資訊或未授權著作全文。
- 新聞只連回原始出版頁面；學生以自己的話建立證據卡。
- OpenStax 內容採短篇改寫與原始連結，不複製章節或圖表。
- GitHub repository 不應放入 API 金鑰、學生作答或含個人資料的匯出檔。
